# Kit: optional scaffolding, never the path

`base.css` and `charts.js` are tokens and utility components (tables, chips, inputs, segmented
controls, basic charts) tuned to the execution numbers in `../../references/craft.md`. Use them for
the secondary 60% of a screen so that part is correct without effort. The hero, the signature
element and the composition are designed from the references for this product, by hand, every time.

`examples/` holds the same business-banking content rendered in four stances. They show the
execution floor (type, spacing, chips, tables) and prove the tokens flex. They are not templates:
do not reuse their layout, hero, copy or stance. If an output resembles one of them, the design
step was skipped.
